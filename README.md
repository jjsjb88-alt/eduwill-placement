# 편입 배치상담

기존 상담 콘솔: `index.html`.

학교·학과 자료 조회: `reference-2026.html`. 검수한 상담자료 JSON 파일을 **자료 불러오기**로 선택하면 학교·학과 검색, 전형·계열·캠퍼스 필터, 관심 학과, 최대 4개 학과 비교 및 원문 확인을 사용할 수 있습니다. 불러온 자료는 해당 탭 메모리에서만 조회하며 새로고침하면 다시 선택해야 합니다. 관심 학과의 식별자만 브라우저에 저장합니다.

이 저장소는 공개입니다. 내부 상담자료 JSON·엑셀 및 자료가 포함된 로컬 HTML을 커밋하지 마세요. 이 조회기는 로그인 서비스가 아니며 자료를 서버로 업로드하거나 자동 동기화하지 않습니다. 직원 공용 로그인과 서버 저장은 별도 인증·권한 구성이 필요합니다.

평균·최고·최저와 TOEIC·필기 지표는 구분해서 표시합니다. 공동모집과 학과별 최대 인원은 합산하지 않습니다. 원문 상충 및 캠퍼스 미배정 자료는 확인 필요로 유지합니다. 기존 학생 판정 계산에는 이 조회기 자료를 자동으로 연결하지 않습니다.

`index.html`은 기존 개발 프로젝트에서 빌드한 파일입니다. 향후 재빌드 때 `data-reference-2026` 메뉴와 `reference2026Entry` 진입 카드, `reference-2026.html`·CSS·JS를 함께 유지해야 합니다.
