# 편입 배치상담

상담 콘솔: `index.html`. 학교·학과 자료: `reference-2026.html`.

공용 비밀번호를 입력하면 화면과 검수 자료가 자동으로 열립니다. 별도의 계정 가입·로그인이나 자료 파일 선택은 없습니다. 학교·학과 검색, 전형·계열·캠퍼스 필터, 관심 학과, 최대 4개 학과 비교 및 원문 확인을 사용할 수 있습니다.

한글 비밀번호와 그에 대응하는 두벌식 영문 자판 입력을 함께 지원합니다. `password-keyboard.js`가 한글 음절을 영문 키 배열로 정규화하며 빌드와 브라우저가 같은 규칙을 사용합니다. 비밀번호 자체나 대체 입력값은 소스에 넣지 않습니다.

이 저장소는 공개입니다. 내부 자료와 기존 상담 HTML은 gzip 압축 후 AES-256-GCM으로 암호화한 `app.enc.json`·`reference.enc.json`으로만 제공합니다. 비밀번호는 PBKDF2-SHA256으로 키를 만들 때 사용하며 소스에 포함하지 않습니다. 원본 자료·복호화한 HTML·비밀번호·키를 저장소에 커밋하지 마세요. 암호문은 내려받을 수 있으며 서버가 시도를 제한하는 계정 인증 서비스와는 구별됩니다.

잠금 해제 키는 현재 탭의 sessionStorage에만 보관하며 비밀번호 원문은 저장하지 않습니다. 내부 링크로 연 탭은 이 세션을 이어받습니다. **잠그기**를 누르면 같은 출처의 열려 있는 상담 탭을 잠급니다. 새 브라우저 세션에서는 비밀번호를 다시 입력해야 합니다. 공유 기록·학생별 계정·서버 자동 동기화는 구현하지 않았습니다.

평균·최고·최저와 TOEIC·필기 지표는 구분해서 표시합니다. 공동모집과 학과별 최대 인원은 합산하지 않습니다. 원문 상충 및 캠퍼스 미배정 자료는 확인 필요로 유지합니다. 기존 학생 판정 계산에는 이 조회기 자료를 자동으로 연결하지 않습니다.

화면 원본은 별도 개발 프로젝트와 비공개 로컬 작업 폴더에서 관리합니다. 원본 템플릿을 수정한 뒤 같은 비밀번호로 암호화 빌드를 다시 수행해야 합니다. 기존 개발 프로젝트의 평문 index를 이 저장소에 그대로 덮어쓰면 잠금이 해제되므로 그렇게 배포하지 마세요. 비밀번호 변경 시에는 두 암호문을 함께 새로 생성합니다.
