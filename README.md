# 서정빈 배치상담실

첫 화면과 전 분원 배치상담 주소에서 모의고사 상담용 암호를 입력한 뒤 학생 이름 전체로 조회합니다. 동명이인은 분원과 끝번호로 선택합니다. 인문·자연, 일반·학사, 학교·학과별로 결과를 확인할 수 있습니다.

도전 학과 중 최근 3개월 성적 구간이 과거 합격자 구간에 닿는 학과에는 보조 문구를 표시합니다. 상담 시연은 ‘가상서하’로 조회할 수 있습니다.

모의고사 판정과 자료 생성은 별도로 관리하는 PC 원본에서 이루어집니다. 게시 대상은 조회 화면과 암호화된 결과입니다. 상담 종료를 누르면 다시 잠깁니다. 운영 암호, 이름 원장, 개별 성적 원본과 판정 코드는 이 저장소에 추가하지 마세요.

### 시험별 백분위와 공동석차

응시 성적 표의 기존 7개 값과 상단 상담용 백분위·판정 계산은 바꾸지 않는다. 보호된 개인별 결과를 만드는 PC 원본에서 같은 시험·과목·응시자 집단의 공동석차용 근거를 검증한 경우에만 해당 `history` 행의 여덟 번째 값으로 `{ "above": 12, "count": 100 }` 형식(예시는 가상)을 넣을 수 있다. `above`는 해당 점수를 초과한 응시자 수, `count`는 본인을 포함한 전체 응시자 수다. 화면은 기존 응시자 수와 일치하는 근거에만 `(above + 1) / count × 100`을 적용한다. 기존 보고서와 근거가 없는 행은 공동석차 기준 상위 %를 미표시(—)한다. 백분위를 100에서 빼어 대신 표시하지 않는다. 근거는 암호화 결과에만 넣고, 원자료·분포·학생 식별정보는 저장소에 추가하지 않는다.
